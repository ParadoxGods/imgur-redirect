What happens

Narrow by design.

This is an image viewer, not an open proxy. It accepts only exact Imgur hosts and conservative image paths.

  1. 01

    Validate

    Reject deceptive hosts, credentials, ports, galleries, albums, videos, and unsupported files.

  2. 02

    Relay

    Use GitHub's public Markdown endpoint to obtain an anonymized Camo image URL.

  3. 03

    Verify

    Check the returned host and encoded source before the browser is allowed to load it.

Independent utility. Not affiliated with or endorsed by Imgur or GitHub. GitHub sees the relay requests, Camo URLs are not secret, browser and Camo caches may persist, and availability is best-effort. Only view or share content you are permitted to access.
